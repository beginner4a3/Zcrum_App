Jira Clone - Project Management App
This is a full-stack project management application inspired by Jira, built to demonstrate industry-standard development practices using the latest technologies. The app, named Scrum, provides features essential for managing Agile workflows and is designed to mimic real-world production-grade applications.

Key Features
Authentication: Supports Google sign-in and custom email/password login.
Organization Management: Create or join organizations with multi-project support.
Project Management: Handle multiple projects, each containing multiple sprint cycles.
Issue Tracking: Add, update, reorder, and filter issues within sprints.
User-Friendly UI: Fully responsive design using Next.js, ShadCN UI, and Tailwind CSS.
Dynamic Components: Includes carousel, accordion, and reusable UI components.
Database Integration: Backend powered by NeonDB, with well-structured database models for users, organizations, projects, and issues.
API Calls and State Management: Efficient data fetching and server-side rendering.
Role-Based Access: Admin-only functionality for certain actions like project creation.
Tech Stack
Frontend: Next.js, Tailwind CSS, ShadCN UI
Backend: NeonDB, Node.js
Authentication: Clerk
